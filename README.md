# 🚚 FedEx Logistics Optimization – SQL Analysis

## 📌 Overview

This project focuses on analyzing logistics operations using SQL to identify inefficiencies in delivery routes, shipment delays, warehouse performance, and delivery agent efficiency.

---

## 🧠 Objective

* Analyze delivery delays and route performance
* Evaluate warehouse and delivery agent efficiency
* Optimize logistics operations using data-driven insights

---

## 🛠️ Tools Used

* SQL (MySQL Workbench)
* Data Cleaning & Validation
* Data Analysis

---

## 📊 Key Analysis Performed

### 🔹 Data Cleaning & Preparation

* Handled missing values (NULL delay hours)
* Validated date consistency
* Ensured referential integrity

### 🔹 Delivery Delay Analysis

* Calculated actual delivery delays
* Identified top delayed routes
* Ranked shipments by delay

### 🔹 Route Optimization

* Evaluated route efficiency
* Identified underperforming routes
* Analyzed delay percentages

### 🔹 Warehouse Performance

* Compared shipment delays across warehouses
* Ranked warehouses based on performance

### 🔹 Delivery Agent Performance

* Ranked agents based on on-time delivery
* Identified underperforming agents

### 🔹 KPI Reporting

* Calculated on-time delivery percentage
* Measured average delays and performance metrics

---

## 📁 Files Included

* SQL Queries
* Project Report
* Analysis Documentation

---

## 🚀 Outcome

This project demonstrates how SQL can be used to analyze real-world logistics data, identify inefficiencies, and provide actionable insights to improve delivery performance and operational efficiency.
